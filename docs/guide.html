Portable executable wrapper for scripts and nearby tools.

overlay-launcher gives a folder-local command a real Windows .exe entry point. Use it when a shortcut, .cmd file, PowerShell script, or symlink is not enough.

Input A generic launcher, a templated JSON config, and optionally an icon.
Output A renamed .exe that carries its own config.
Runtime The exe reads itself, expands paths like @{exe_dir}, edits env, and starts the command.
mental model build once, stamp many
overlay-launcher.exe The generic self-reading launcher.
+
config.json + logo.ico What to run, where to run it, env, args, and icon.
=
my-tool.exe A portable executable wrapper for your actual tool.

Make One

Build the tools

From the repository root:

zig build

Write a config

Config is templated JSON. Start small; every command entry is one argv item.

{
  "terminal": true,
  "cwd": "@{exe_dir}",
  "command": ["cmd.exe", "/C", "echo exe=@{exe_path} && pause"]
}

Stamp the executable

The icon is optional, but this is how the output exe gets one.

zig-out\bin\overlay-launcher-stamp.exe `
  --launcher zig-out\bin\overlay-launcher.exe `
  --config examples\config.json `
  --icon path\to\logo.ico `
  examples\demo-launcher.exe

Run or move it

The stamped exe can be copied or renamed. Runtime paths are resolved from the final exe location.

examples\demo-launcher.exe --user-arg value

Config Shape

Most launchers need only cwd, env, and command. Leave terminal unset or true for visible console programs; set it to false for quiet background launches.

Command is argv

Do not pack the whole command line into one string unless you are intentionally launching a shell.

{
  "command": [
    "python.exe",
    "-m",
    "my_module",
    "--input",
    "file with spaces.json"
  ]
}

Env is ordered

Later env values can read earlier edits. Missing env values return empty unless strict mode is enabled.

{
  "env": {
    "PATH": "@{env:"PATH":prepend_env(exe_parent:join("python"))}",
    "PATH_AFTER": "@{env:"PATH"}"
  }
}

Templates You Will Actually Use

Templates use @{...}. Inside template expressions, use normal quotes, for example join("python"). The launcher preprocesses templates before JSON parsing.

TemplateUse
@{exe_path}Full path to the stamped exe.
@{exe_dir}Directory containing the stamped exe.
@{exe_parent}Parent of exe_dir, useful for bundle\bin\tool.exe.
@{exe_parent:join("app")}OS-correct path joining.
@{env:"PATH"}Current environment, including earlier config edits.
@{args}All user arguments, spliced into a command array.
@{args:1}First user argument. User args are 1-based.
Literal text: write @@{ when you need a literal @{. Plain braces are not special, so PowerShell blocks such as { $_.Name } are fine.

Python Module Recipe

A common portable bundle keeps the launcher in bin, Python in python, and app code in app.

bundle\ bin\ my-tool.exe python\ python.exe app\ my_module\ __main__.py
{
  "terminal": true,
  "cwd": "@{exe_parent:join("app")}",
  "env": {
    "PYTHONHOME": "@{exe_parent:join("python")}",
    "PYTHONPATH": "@{exe_parent:join("app")}"
  },
  "command": [
    "@{exe_parent:join("python"):join("python.exe")}",
    "-m",
    "my_module",
    @{args}
  ]
}

Rules That Save Time

Use a shell only for shell behavior

Use cmd.exe /C or PowerShell only for redirection, pipelines, built-ins, or shell variable expansion.

Splices stand alone

@{args} can insert many command entries only when it is the whole array item.

Duplicate keys are errors

Config object keys are literal, ordered, and cannot be templated.

The stamp helper is optional

Other tools can copy the base exe, update resources, append the start marker, then append UTF-8 config bytes.
